# 기여자 로드맵

처음 참여하는 분이 범위를 쉽게 판단할 수 있도록 작은 작업부터 정리했습니다. 큰 기능을 구현하기 전에는 이슈를 열거나 기존 이슈에 참여 의사를 남겨 주세요.

## 처음 맡기 좋은 작업

1. 다른 Agent Skills 호스트에서 사용하는 `allowed-tools` 형식의 짧은 예제를 추가합니다.
2. 계약 참조 문서를 읽어야만 이해할 수 있는 오류 메시지를 더 명확하게 고칩니다.
3. 이식성 검사기가 허용하거나 차단해야 할 경로 형식을 합성 자료로 추가합니다.
4. `skill-contract.yaml`과 저장소의 JSON Schema를 편집기에서 연결하는 방법을 문서화합니다.
5. pre-commit 설정 예제를 추가하고 임시 저장소에서 실제로 동작하는지 검사합니다.

## 도움이 필요한 작업

1. 일치한 원문을 노출하지 않는 SARIF 출력 형식을 설계합니다.
2. 경로 해석을 명시적으로 유지하고 순환 참조를 막는 계약 상속 기능을 설계합니다.
3. frontmatter 오류에도 정확한 줄 번호를 표시합니다.
4. 단독 실행 바이너리를 패키징하고 재현 가능한 빌드 방법을 문서화합니다.
5. 대소문자를 구분하는 파일 시스템과 구분하지 않는 파일 시스템의 동작을 비교합니다.

## 지켜야 할 설계 원칙

- 모든 검사는 결정적이어야 하며 네트워크 연결 없이 동작해야 합니다.
- 오류 결과에는 실제로 일치한 원문을 기본적으로 표시하지 않습니다.
- 계약 경로는 선언한 루트 밖으로 나갈 수 없습니다.
- 새 테스트 자료는 합성 데이터로 작성합니다.
- 새 규칙 유형에는 성공, 실패, 잘못된 입력, CLI 출력 테스트를 함께 추가합니다.
