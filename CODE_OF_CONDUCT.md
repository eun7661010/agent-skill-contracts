# Code of conduct

We want this project to be a practical and welcoming place to improve open tooling.

## Expected behavior

- Discuss ideas and code without attacking the person who proposed them.
- Ask for evidence, explain tradeoffs, and acknowledge uncertainty.
- Make room for contributors with different languages, backgrounds, and experience levels.
- Protect private data. Replace real skills, paths, credentials, and customer information with synthetic examples.
- Accept a maintainer’s request to pause discussion when privacy, safety, or licensing needs review.

## Unacceptable behavior

Harassment, threats, discriminatory language, sexualized attention, doxxing, deliberate disclosure of private data, and repeated disruption are not acceptable in project spaces.

## Reporting and enforcement

For a private report, use the repository’s private vulnerability reporting form and mark the report as a conduct matter. Do not repeat sensitive information in a public issue.

Maintainers may edit or remove content, close discussions, restrict participation, or ban an account when necessary to protect contributors and the project. Decisions should be proportionate, documented privately, and based on the behavior rather than a person’s identity or viewpoint.

This policy applies to repository issues, pull requests, discussions, release notes, and other spaces represented as part of the project.
