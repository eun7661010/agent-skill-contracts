## [0.1.0] - 2026-08-21

### Added

- Deterministic text and regular-expression rules with `all`, `any`, and `forbid` semantics
- Required file, reference, frontmatter, and tool declaration checks
- User-specific absolute path and external symlink portability checks
- Recursive YAML and JSON contract discovery
- Text, JSON, and GitHub Actions annotation output
- Composite GitHub Action, cross-platform CI, JSON Schema, and synthetic examples
